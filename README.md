# 英语奇趣岛 · 儿童英语学习 H5 小游戏（高档版）

## 一、项目简介
- 目标年龄：3~12 岁儿童（分三个年龄组：3~5岁 / 6~8岁 / 9~12岁）
- 运行平台：手机浏览器 / 微信内打开的 H5 网页
- 技术：HTML + CSS + JavaScript（纯前端，无需服务器）
- 发音：有道翻译 TTS 在线接口（`dict.youdao.com/dictvoice`），失败自动回退浏览器 Web Speech API
- 图片：Emoji 图标 + 纯 CSS 颜色块（颜色主题），无需外部图片素材

## 二、文件结构（代码按功能模块组织）
```

│   ├── game-listening.js   题型1：听音找图（含动态难度调整）

```

## 三、高档项目完成内容

### 3.1 主题与词汇
- 8 个主题：动物、水果、颜色、食物、交通工具、身体、家庭、动作
- 每个主题 15~20 个词，合计 **160 个词汇**
- 30 个短句/情境表达（用于句子排序和情境选择）

### 3.2 三种任务类型（实际实现四种）
| 任务类型 | 适用年龄 | 玩法说明 |
|---------|---------|---------|
| 听音找图 | 3~5岁起 | 播放单词发音，从2~4张图中选答案 |
| 词图配对 | 6~8岁起 | 左边图片、右边单词，点选配对 |
| 拼单词 | 6~8岁起 | 看图片/听发音，从打乱字母中拼出单词 |
| 句子排序/情境选择 | 9~12岁 | 打乱句子成分排序，或根据情境选正确表达 |

### 3.3 三个关卡难度 + 动态调整（可测试复现）
听音找图游戏包含三个难度等级，并根据答题表现自动调整：

| 难度 | 选项数 | 说明 |
|------|--------|------|
| 简单 easy | 2张图 | 入门级，二选一 |
| 中等 normal | 3张图 | 进阶级，三选一 |
| 困难 hard | 4张图 | 挑战级，四选一 |

**动态调整规则（可测试复现）：**
1. 初始难度由 `GameListening.start(theme, level, onFinish)` 的 `level` 参数决定
2. **连续答对 3 题**：难度 +1（easy → normal → hard）
3. **连续答错 2 题**：难度 -1（hard → normal → easy）
4. 难度边界：最低 easy，最高 hard
5. 答对/答错打断连续计数时，连续计数重置
6. 升级/降级后连续计数重置，重新累计

**测试方法：**
- 选简单难度开始，连续答对3题后，第4题选项从2张变成3张（升级到中等）
- 再连续答对3题，选项从3张变成4张（升级到困难）
- 在困难难度连续答错2题，选项从4张变回3张（降级到中等）

### 3.4 学习数据记录
- 完成轮数（totalRounds）
- 总答题数、答对数、总正确率（getAccuracy，上限100%）
- 各主题/各玩法最高分（bestScore）
- 错题本（wrongWords）：答错自动收录，答对自动移除
- 已解锁主题（unlockedThemes）：正确率≥60%解锁下一个主题
- 学习报告页：总览数据 + 各主题正确率柱状图

### 3.5 错题复习入口
- 结算页显示"📕 错题本：N 个词待复习"按钮
- 点击进入错题复习模式（用听音找图玩法跑错词）
- 复习中答对的词自动从错题本移除

### 3.6 游戏控制功能
| 功能 | 实现方式 |
|------|---------|
| 静音 | 顶部🔊按钮，切换静音/取消，状态持久化到localStorage |
| 重播 | 每题"🔊 再听一次"按钮，可无限次重播 |
| 暂停 | 顶部⏸️按钮，弹出暂停遮罩，可继续或退出 |
| 退出 | 顶部🚪按钮，弹出确认对话框"确定要退出当前关卡吗？进度会丢失哦~" |

## 四、如何在手机上测试
1. 把整个 `english-island-high` 文件夹上传到 GitHub 仓库
2. 仓库 Settings → Pages → Source 选 main 分支 / root 目录
3. 等待2~5分钟，用手机浏览器打开 `https://用户名.github.io/english-island-high/`
4. 或在微信里打开链接（微信内置浏览器可正常发音）
5. 本地测试：在文件夹内运行 `python -m http.server 8000`，手机和电脑同一WiFi下访问 `http://电脑IP:8000`
